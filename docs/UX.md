# Switchboard UX

- 문서 상태: v1 확정안 (2026-11-02)
- 관련: [ARCHITECTURE.md](ARCHITECTURE.md) §4, §5.1

## 0. 목표

요청 하나 = **단축키 → 클릭 → 입력 → `Ctrl+Enter`**, 네 동작이면 끝난다. 추천이 맞으면 세션을 고르는 동작은 0번이다.

## 1. 원칙

1. **페이지를 건드리지 않는다.** 레이아웃, 스크롤, 포커스가 바뀌지 않아야 한다. 사이드바를 기본 화면으로 쓰지 않는 이유가 이것이다. 사이드바가 붙으면 페이지 폭이 줄어 반응형 레이아웃이 바뀌므로, 고치려던 화면이 선택하는 순간 달라진다.
2. **모드가 없다.** 선택 도구는 1회성이라 선택이 끝나면 자동으로 꺼진다. 클릭(요소)과 드래그(영역)는 같은 도구 안에서 구분하며, 따로 전환하지 않는다.
3. **키보드로 끝까지 간다.** 마우스는 대상을 짚을 때만 쓴다.
4. **짧은 글자만 쓴다.** 제목과 버튼은 1~2단어, 설명 문장과 부제는 없다. 부연은 툴팁으로만 한다. 상태는 문장이 아니라 단어로 표시하고, 태그에 이모지나 아이콘을 붙이지 않는다.
5. **기다리게 하지 않는다.** 추천은 캡처하는 순간 시작해서 입력하는 동안 끝난다. 늦게 온 결과(LLM 재순위)가 순위를 바꿔도, 사용자가 이미 세션을 고쳤다면 덮어쓰지 않는다.
6. **실수 비용을 낮춘다.** 초안은 자동 보존하고, 붙여 넣을 전문은 미리보기로 확인할 수 있다. 응답 대기 중인 세션에는 절대 입력하지 않는다.

## 2. 화면 4개

| 화면 | 위치 | 언제 |
| --- | --- | --- |
| 선택 오버레이 | 페이지 위 (top layer) | 단축키를 누른 뒤 선택을 마칠 때까지 |
| 작성 팝업 | 선택한 요소 옆 (top layer) | 선택 직후 |
| 상태 칩 | 화면 오른쪽 아래 (top layer) | 보낸 뒤 완료 확인까지 |
| 사이드 패널 | Edge 사이드바 | 필요할 때만 (세션 현황, 기록, 설정) |

페이지 위 UI는 모두 Shadow DOM 안에서 HTML `popover`(top layer)로 띄운다. 페이지 CSS나 z-index와 경쟁하지 않고, 레이아웃에도 영향을 주지 않는다. 페이지는 팝업이 떠 있는 동안에도 그대로 조작할 수 있다(비모달).

## 3. 흐름

### 3.1 시작

| 방법 | 동작 |
| --- | --- |
| `Alt+Shift+S` | 선택 도구 시작. 팝업이 떠 있어도 새로 시작해 여러 개를 동시에 쓴다 |
| 툴바 아이콘 클릭 | 같음 |
| 우클릭 → `Switchboard` (P1 후반) | 우클릭한 요소를 바로 선택하고 작성 팝업 열기 |

단축키는 `edge://extensions/shortcuts`에서 바꿀 수 있다.

### 3.2 선택 오버레이

```
   +-----------------------------+
   |  [ Avatar v ]               |    2px accent outline + 10% fill
   +-----------------------------+
   AvatarMenu   button.avatar   AvatarMenu.tsx:58
```

- 마우스를 올리면 요소 테두리와 이름표(컴포넌트, 선택자, 파일:줄)가 뜬다. 커서는 십자 모양이다.
- 소스 위치는 150ms 머문 뒤 찾고, 요소별로 캐시한다. 못 찾으면 선택자만 표시한다.
- **클릭**: 요소 선택. **드래그**(6px 이상 움직임): 영역 선택. 점선 사각형이 그려진다.
- `↑`/`↓`: 부모·자식 요소로 이동. `Shift+클릭`: 추가 선택(도구 유지, `Enter`나 일반 클릭으로 마침). `Esc` 또는 우클릭: 취소.
- 선택 도구가 켜진 동안에는 페이지의 클릭 이벤트를 막는다. 버튼을 짚어도 그 버튼이 실행되지 않는다. 휠 스크롤은 그대로 된다.
- 캡처할 때는 오버레이를 숨기고 두 프레임을 기다린 뒤 찍는다. 테두리가 스크린샷에 찍히지 않게 하기 위해서다.

### 3.3 작성 팝업

추천 신뢰도가 높을 때 (기본):

```
 AvatarMenu  ·  AvatarMenu.tsx:58                         x
 ──────────────────────────────────────────────────────────
 모바일에서 드롭다운이 잘림. 화면 안에 들어오게
 ──────────────────────────────────────────────────────────
 shop-web-71   유휴   소스 일치  최근 수정        v
                                         미리보기   보내기
```

신뢰도가 낮고 이 사이트에서 고른 세션도 없으면 세션을 비워 둔다(`▸▸ 세션 ▾`, 보내기 꺼짐). 목록은 자동으로 펼치지 않는다(2026-11-02 사용자 지적: 기본으로 열리면 방해). 세션 줄 클릭이나 `alt+↓`로 열면:

```
 AvatarMenu  ·  AvatarMenu.tsx:58                         x
 ──────────────────────────────────────────────────────────
 |
 ──────────────────────────────────────────────────────────
 추천
 1  shop-web-71   유휴      주제
 2  shop-web-af   작업 중   주제
 전체
    api-a0                작업 중   ~/api
    document creation…    보기 전용
                                         미리보기   보내기
```

- **위치**: 선택 영역의 오른쪽, 자리가 없으면 아래·왼쪽·위 순서로 놓는다. 화면 밖으로 나가면 안쪽으로 밀어 넣는다. 머리줄을 끌어 옮길 수 있다. 너비는 360px이다.
- **스크린샷 미리보기**: 머리줄 맨 앞의 작은 썸네일이 실제로 보낼 잘라 낸 스크린샷이다. 누르면 머리줄 아래로 크게 펼친다(작은 요소는 2배까지 키움). 선택을 마칠 때 찍은 화면을 서비스 워커에서 잘라 줄인 사본(WebP)을 쓰므로 페이지를 다시 그리지 않는다. 페이지 CSP에 막히지 않게 `<img>` 대신 canvas에 그린다.
- **머리줄**: 대상 이름과 파일:줄. 경로는 가운데를 줄여서 표시하고, 전체 경로는 툴팁으로 보여 준다. 클릭하면 선택자, 컴포넌트 스택, 주요 스타일이 펼쳐진다. 영역을 선택했으면 `영역 320×180 · Header`, 여러 개를 선택했으면 `요소 3개`로 표시한다.
- **입력칸**: 열리자마자 포커스가 간다. 2줄에서 시작해 8줄까지 늘어난다. 안내 문구는 `요청` 한 단어다.
- **세션 줄**: 추천 1위가 미리 선택된다. 이름, 상태, 근거 태그를 보여 준다. 추천 계산 중에는 `…`로 표시한다.
- **기본 버튼**은 선택한 세션 상태에 따라 바뀐다(§4).
- **초안**: `Esc`나 `x`로 닫아도 30분 동안 탭별로 보존하고, 같은 대상을 다시 고르면 복원한다. 팝업 밖을 클릭해도 닫히지 않는다.

### 3.3.1 여러 팝업과 연계 (2026-11-02)

- **따로**: 팝업이 떠 있어도 `Alt+Shift+S`로 새로 골라 팝업을 더 띄운다. 팝업마다 내용·세션·키 입력이 따로이고, 누른 팝업이 맨 위로 온다(DOM 순서 대신 z-index로 올려 입력 포커스를 지킨다). 근처를 연달아 고르면 겹치지 않게 비켜 뜬다. 세션 목록 조회는 하나로 합친다.
- **연계**: 팝업에서 `alt+a 추가`(또는 키 힌트 클릭) → 선택 모드(덧붙일 팝업만 또렷하게, 점선 테두리) → 고른 요소가 `+2 이름 파일:줄 [썸네일] ✕` 줄로 붙는다. 보내면 프롬프트 하나에 `대상 1`, `대상 2`…가 각자 위치·스크린샷과 함께 들어간다. 연계 대상은 따로 찍으므로 스크롤해서 다른 곳을 고를 수 있다(같은 화면에서 한 번에 고르는 `Shift+클릭`과 다름).
- 연계 대상이 아직 올라가는 중이면 `보내기`를 막는다. 캡처에 실패한 대상은 빼고 보낸다.
- 키 힌트 줄: `alt+a 추가 · alt+l 연결 · alt+p 미리보기` + `보내기 ctrl+⏎`(`연결`은 붙일 다른 요청이 있을 때만). 닫기는 머리줄 ✕(툴팁 `esc`)와 `Esc` 키.

### 3.3.2 다른 페이지 연계(레퍼런스)와 보관 (2026-11-02)

"저 페이지의 저것처럼" 같은 요청을 위해 다른 페이지·탭의 요소를 참고 대상으로 붙인다.

- **alt+a 뒤 다른 페이지에서 고르기**: 팝업에서 `alt+a` → 다른 탭(또는 같은 탭에서 이동한 다른 화면)에서 `Alt+Shift+S` → 위쪽에 `✻ AvatarMenu 요청에 덧붙이는 중 · esc 취소` → 고르면 그 페이지엔 팝업이 뜨지 않고 `→ AvatarMenu 요청에 붙임` 알림만, 원래 팝업에는 `+2 Banner /other.html Banner.tsx:~5` 줄이 붙는다(다른 페이지 대상은 주소 경로를 함께 표시). 원래 페이지의 선택 모드는 자동으로 내려간다. 연계 대기는 5분 뒤 풀린다.
- **alt+l 연결**: 이미 쓴 요청(대상 1 + 덧붙인 것 전부)을 다른 요청에 통째로 붙이고 닫는다. 목록은 `이 요청을 붙일 곳` 아래 이 페이지의 다른 팝업과 다른 페이지·탭의 요청(이름, 경로, 쓰던 글 첫 줄).
- 프롬프트: 대상마다 위치와 스크린샷. 페이지가 섞이면 `- 페이지(대상 1): …`, `- 페이지(대상 2, 3): …/other.html`처럼 페이지마다 한 줄.
- **보관**: 열린 팝업(쓰던 글·고른 세션·덧붙인 대상)과 칩을 백그라운드가 `storage.session`에 둔다(브라우저를 닫으면 사라짐). 초안은 탭+캡처한 주소별, 칩은 탭별. 새로고침하면 localhost 권한이 있을 때 바로 다시 뜨고, 없으면 다음 `Alt+Shift+S` 때 되살아난다. SPA에서 주소가 바뀌면 그 주소의 팝업만 보이고, 돌아오면 다시 보인다. 탭을 닫으면 그 탭 몫은 지운다.

### 3.4 세션 목록

- VS Code 확장 세션은 이름 옆에 `VS Code` 글자 태그. 고르면 기본 버튼이 `복사 ctrl+⏎`(툴팁: 프롬프트를 복사하고 VS Code 탭을 띄움 → ctrl+v · enter). 보내면 알림 `VS Code에서 ctrl+v · enter`, 칩은 `◌ 붙여넣기` → 붙여 넣으면 `작업 중` → `완료`. 칩을 펼치면 `복사`(다시 복사)·`취소`.

- 구성은 **추천**(상위 3개, 번호와 근거 태그)과 **전체**(살아 있는 모든 세션, 프로젝트별 묶음)다.
- 글자를 치면 이름이나 경로로 걸러진다.
- 한 줄에는 이름, 상태, 근거 태그 또는 프로젝트 경로, 마지막 활동 시각이 들어간다.
- tmux 창을 찾지 못한 세션은 `보기 전용`으로 흐리게 표시하고 고를 수 없다.
- 맨 아래 `새 세션`(P4)은 소스 파일이 속한 프로젝트 루트에서 tmux 새 창으로 `claude`를 띄운다.
- 고른 세션은 같은 오리진·파일에서 다음 추천 때 가산점(`이전 선택`)을 받는다.

### 3.5 미리보기

세션에 실제로 붙여 넣을 전문을 고정폭 글꼴로 보여 준다. 사용자가 쓴 문장, 대상 파일:줄, 페이지 주소, 스크린샷 경로, 전체 맥락 파일 경로가 들어간다. 읽기 전용이며, 고칠 것은 입력칸에서 고친다.

### 3.6 상태 칩

보내면 팝업이 화면 오른쪽 아래의 칩으로 줄어든다.

```
                                  #42  shop-web-71  작업 중  1:24
```

- 상태는 `예약` → `전달` → `작업 중` → `완료` / `실패` 순으로 바뀐다. 경과 시간을 함께 표시한다.
- `예약`은 기다릴 이유(세션 작업 중, 응답 대기, 입력칸에 글, 화면 확인 불가, 세션 없음)가 있을 때만 쓴다. 이유가 없으면 곧 들어가는 중이므로 `전달`로 보인다. 이유는 툴팁으로.
- 진행 중인 칩은 0.7초마다 상태를 묻는다(localhost). 세션 없이 저장만 한 요청은 `저장`.
- 칩을 클릭하면 펼쳐진다:

```
 #42  shop-web-71                          완료  2:10
 모바일에서 드롭다운이 잘림. 화면 안에 들어오게
 ──────────────────────────────────────────────────────────
 AvatarMenu.tsx 드롭다운 위치 계산을 viewport 기준으로 …
                                  열기   새로고침   닫기
```

- 완료되면 Claude의 **전체 답변**(마지막 도구 호출 뒤 글, 64KB까지)을 마크다운으로 그린다: 표·목록·코드·제목. HTML은 실행하지 않고 글자로, 링크는 http(s)만 새 탭. 답변 칸만 스크롤(화면 절반까지). 버튼: `새로고침`, `닫기`. 대기 중이면 `취소`.
- **이어서**: 펼친 칩 아래 `❯ 이어서` 입력칸. `alt+a`로 요소를 덧붙일 수 있고(`+1 Card Card.tsx:~10`), `이어서 ctrl+⏎`로 같은 세션에 보낸다. 프롬프트는 `[switchboard #6] …` + `- #5에 이어서` (+ 덧붙인 대상이 있으면 대상·페이지 줄, 없으면 이 두 줄만).
- 여러 건이면 쌓아서 표시하되 3개까지만 보이고 나머지는 `+2`로 줄인다.
- 툴바 아이콘 배지에 진행 중인 건수를 표시한다. OS 알림은 기본으로 끄고 설정에서 켤 수 있다.
- localhost 권한이 있으면 페이지를 새로고침해도 칩이 다시 뜬다(§9).

### 3.7 사이드 패널 (선택)

```
 세션   기록                                              ⚙
 ──────────────────────────────────────────────────────────
 NAME                  STATUS   LAST   PROJECT
 shop-web-71   유휴     2m     shop-web
 shop-web-af   작업 중  now    shop-web
 api-a0                작업 중  now    api
```

- **세션**: ps 형식의 표다. 줄을 클릭하면 최근 프롬프트 5개와 최근 파일이 펼쳐진다.
- **기록**: 요청 목록(문장, 세션, 상태, 이어서 쓴 요청은 `#6 ← #5`). 클릭하면 전체 답변(마크다운), 스크린샷, `보낸 내용`(접힘), `❯ 이어서` 입력칸(`ctrl+⏎`)이 펼쳐진다. 스크린샷은 데몬의 `GET /v1/captures/:id/element.png`(토큰 필요).
- **설정**(`3`, 2026-11-02 구현): 줄마다 `▸▸ 이름` + 값.
  - `데몬`: 연결 상태(`● 연결됨 v0.1.0` / `미연결` / `연결 안 됨`)와 `❯ 주소` 입력 + `적용`. 포트만(`7600`)·`호스트:포트`·전체 주소를 받고, 이 컴퓨터(127.0.0.1·localhost·[::1]) 밖이면 `이 컴퓨터 주소만`(토큰이 새지 않게). 기본 포트가 아니면 그 주소 권한을 그때 요청한다 → 다시 빌드 없이 포트 변경.
  - `자동 복원`: 새로고침 뒤 쓰던 팝업을 바로 다시 띄울 사이트. 허용된 호스트를 `localhost ✕`처럼 보여 주고, `+ localhost` 버튼과 `❯ myapp.test:3000` 입력 + `추가`(스킴이 없으면 http·https, 포트 무관). 권한 목록이 곧 설정이라 따로 저장하지 않는다.
  - `단축키`: 현재 `Alt+Shift+S` + `바꾸기`(브라우저 단축키 설정 페이지).
  - `데몬 설정`: `switchboard config` (포트·실행 파일·보관 기간·추천 가중치·전달 타이밍은 데몬 쪽).
  - 데몬이 꺼져 있어도 설정 탭은 열린다(주소가 틀렸을 때 고칠 수 있게). 연결 끊김 줄에도 `주소` 버튼.
- **연결**(처음 한 번): WSL에서 `switchboard pair`를 실행하면 나오는 6자리 코드를 입력한다.

## 7. 시각 디자인 — Claude Code 터미널 문법 (2026-11-02 개편)

페이지 위 패널이지만 Claude Code 화면처럼 읽히게 한다.

| 요소 | 문법 |
| --- | --- |
| 색 | Claude 아이보리 `#FAF9F5` / 다크 `#262624` 바탕, 강조색은 Claude 오렌지(`#D97757`, 라이트는 대비를 위해 `#C15F3C`) 하나. 상태색: 유휴 초록, 작업 중 오렌지(Claude Code 스피너 색), 대기 황토, 실패 빨강 |
| 글꼴 | 전부 고정폭 13px 한 크기(Cascadia Mono → Consolas → … → 맑은 고딕). 위계는 색과 굵기로만 |
| 머리줄 | `✻ 컴포넌트  파일:줄  [썸네일] ✕` |
| 입력 | 가로선 사이 `❯ 요청` (Claude Code 입력칸) |
| 세션 | 접힘: `▸▸ 세션이름 상태   근거 · 근거 ▾` (Claude Code 하단 상태줄). 펼침: `❯ 1. 세션이름 상태 근거` (Claude Code 선택 목록, 선택 줄만 ❯와 오렌지) |

| 칩 | 진행 중 `✻` 스피너(· ✢ ✳ ✶ ✻ ✽ 순환), 예약 `◌`, 끝나면 `●`(초록/빨강). 펼치면 `└ 요청`, `└ 응답 요약` (Claude Code 도구 결과 줄) |
| 사이드 패널 | `✻ switchboard  ● 연결됨`, 탭 `1 세션 · 2 기록`(숫자 키로 전환), 기록은 칩과 같은 줄 문법 |
| CLI | 데몬 시작 `✻ switchboard`, 전달 로그 `✻ #3 …` / `● #3 … done`, 세션 표의 busy는 오렌지 |

글꼴에 없거나 Windows에서 컬러 이모지로 그려질 수 있는 기호(`⏵` `⎿` `⏺` `✳`)는 `▸` `└` `●`로 바꾸거나 텍스트 표시 선택자(U+FE0E)를 붙였다. 태그에는 이모지를 쓰지 않는다.

이전 안(시스템 글꼴, 파란 강조색)은 아래에 남긴다.

### 이전 안

- **테마**: OS의 라이트/다크 설정을 따른다. 색은 Shadow root의 `:host` 토큰으로 정의한다.
- **글꼴**: 시스템 UI 글꼴. 경로·선택자·시간은 고정폭(`ui-monospace`, Windows에서는 Cascadia Mono)과 tabular-nums를 쓴다.
- **밀도**: 기본 13px, 팝업 너비 360px, 줄 높이 28px.
- **색**: 강조색 하나와 상태색(유휴 초록, 작업 중 파랑, 대기 주황, 실패 빨강). 상태는 항상 글자와 함께 표시하고 색만으로 구분하지 않는다. 대비는 WCAG AA 이상.
- **움직임**: 120ms 페이드·스케일만 쓴다. `prefers-reduced-motion`이면 끈다.
- **오버레이**: 요소는 2px 강조색 테두리 + 10% 채움, 영역은 점선 사각형.

## 8. 예외 상황

| 상황 | 처리 |
| --- | --- |

| `body`·`html`처럼 너무 큰 요소 | 뷰포트 스크린샷만 첨부 |

| 소스 위치를 못 찾음 | 머리줄에 선택자를 표시하고, 데몬이 ripgrep으로 보강 |
| HMR 전체 새로고침 | localhost 권한이 있으면 상태 칩 복원, 없으면 아이콘 배지로만 표시 |

## 9. 권한과 주입 방식

- 설치할 때 모든 사이트 권한을 요구하지 않는다. 단축키나 아이콘을 누르면 `activeTab`으로 **그 탭에만** 임시 권한이 생기고, 그때 오버레이와 probe를 주입한다.
- 고정 권한은 기본 데몬 주소(`127.0.0.1:7490`)뿐이다. 그 밖은 `optional_host_permissions`(`http://*/*`, `https://*/*`)로 선언만 해 두고, 사이드 패널 설정에서 사용자가 고른 곳(자동 복원 사이트, 기본이 아닌 데몬 포트)만 그때 요청한다. 거절해도 기본 흐름(단축키 → activeTab)은 동작한다.
